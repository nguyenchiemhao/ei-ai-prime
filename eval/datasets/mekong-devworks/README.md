# Mekong Devworks bilingual test set (EVL-01)

Mekong Devworks is a fictional company. Every name, phone number, email, ID number, URL and figure in this folder is invented for testing.

Version: 1.0 — 2026-10-13
Review status: Pending owner review (every item is LLM-drafted; see Provenance and limitations).

One shared, labelled, bilingual (English / Vietnamese) test set for the Classifier (PIPE-02), the Script Matcher spike (EVL-04) and the Jev spike (JEV-04): 40 Answer Scripts and 430 test questions, each labelled with a question type and the correct script.

## Record formats

See `labeling_guide.md` section 2 (question record: `id, group, language, history, question, type, correct_script`, plus `source`). Scripts have `id, title, set, questions_en, questions_vi, answer_en, answer_vi, mode, action_type, action_value, status, start_date, end_date` and an optional `near_duplicate_of`.

## How to validate

```
node --test "eval/datasets/mekong-devworks/checks/*.test.mjs"
node eval/datasets/mekong-devworks/tools/validate.mjs
```

Run both commands from the repository root: `node --test` with a glob that matches no file prints `tests 0` and exits 0, so a CI job must fail when it reports 0 tests (hand-off for EA-13). The first command runs all checks; the second prints `OK: 40 scripts, 430 questions (...)` and exits 0, or prints one line per error (`file:line rule message`) and exits 1. Node 22 expands the quoted glob itself. After editing `scripts.jsonl` regenerate the CSV with `node eval/datasets/mekong-devworks/tools/build-scripts-csv.mjs`. CI wiring pending SET-03 (EA-13): its Node checks list should include the first command.

Cross-labelling: `node eval/datasets/mekong-devworks/tools/cross-labelling.mjs agreement <fileA> <fileB>` (paths relative to this folder). See `agreement_report.md` section 6 for the human pass.

## Usage notes for EVL-04 and JEV-04

- Every script is a candidate regardless of status or dates: the set measures matching quality, not activation rules. Do not filter by `status`; otherwise `ot-public-holiday` (draft), `tet-holiday-2027` (scheduled) and `year-end-party-2025` (expired) would lose their questions.
- Split train/test by script (70/30), not by question. Every script except `talk-to-hr` has at least 2 group A questions; each of the 18 near-duplicate pair members has at least 2 group C questions.
- `talk-to-hr` (a hand-off action) has no test question on purpose: hand-off requests are group F with `NONE`. Its example questions are close to those group F questions, so a Matcher that returns `talk-to-hr` for them is doing the right thing: exclude groups E, F and G from the Matcher's NONE-precision (they are meant for the Classifier), or count a `talk-to-hr` match on a group F handoff question as correct.
- `group` allows the group B / C / H break-downs; group H questions carry fake personal data for the masking-effect measurement.
- `source` is `llm-draft` for every question so that human-written questions can be added later and reported separately.
- Group G questions carry 1-2 history turns; the other groups have `history: []`.

## Provenance and limitations

- **Cross-labelling.** The second labeller is an independent LLM pass (a different model, fresh context, blind), the ticket's fallback, because the team cannot provide human labellers. Both labellers are LLMs of the same vendor, so the agreement is likely overstated (see `agreement_report.md` for the figures and the sample composition). The human pass (owner + one outsider) is prepared: see `agreement_report.md` section 6.
- **LLM-drafted.** All scripts and questions were drafted by a model and still need review by a person; the owner review of every item is pending. Groups A and B were not written by outsiders (jev-spike section 11), so the set may be easier than real traffic.
- **Fake personal data.** Emails use reserved domains and URLs use `*.example`. Vietnam has no reserved fictional phone range, so a made-up phone or ID number could belong to a real person by accident. The numbers are never dialled or used outside this folder.
- **No CI yet.** The checks run by hand until SET-03 (EA-13) exists.
