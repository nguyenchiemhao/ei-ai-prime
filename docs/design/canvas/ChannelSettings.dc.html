Embed

1 · Add this to every page of your portal:

<script src="https://cdn.ei-ai.example/widget.js" data-channel="ch_emp_portal" async></script>

2 · Give the widget a fresh token from your backend:

EiAI.setTokenProvider(() => fetch("/api/ei-ai-token").then(r => r.text()));

Signing examples: Node · PHP · .NET · Java · Python. If your site sets a Content-Security-Policy, allow cdn.ei-ai.example in script-src and frame-src.
